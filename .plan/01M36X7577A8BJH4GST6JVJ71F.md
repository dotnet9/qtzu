# 天空群岛：跳上去取蛋 → 孵化 → 跳下来找其他蛋（闭环玩法）

前置：`main` @ `405cb54`，工作区干净。
触发：用户说"做点好玩的功能，比如前面说的天梯跳跃，跳上去是悬浮的天空岛，上面放 2~3 颗蛋，
孵化完再跳下去找其他蛋"；并明确"不要局限于天空岛现在这个简陋的玩法"，"可用桥相连，也可以跳过去"，
"环境也要逼真"，且要求多问、让他选择。

用户决定（已选定）：
1. **每座城市上空**都有一片天空群岛（不只是农场岛那一座）
2. **四条上/下岛通道全做**：云梯跳 / 上升气流（吹上去·飘下来）/ 词宠驮着飞 / 从长城架桥
3. **四种岛间连接全做**：跳过去 / 木桥相连 / 会浮的云踏板 / 弹簧花·蘑菇跳板
4. **岛上五样全做**：2~3 颗蛋 / 宝箱（稀有词宠或配饰）/ 单词挑战开机关 / 采集与动物 / 环境装饰与远景

## 〇、现状与关键实现结论（都已查证，决定方案形状）

| 事实 | 位置 | 对方案的意义 |
|---|---|---|
| 农场岛已有云朵阶梯（9 级、每级 1.3 米、会上下浮）→ **天空岛 y=14（半径 6，只有一棵树，没有任何玩法）** | `world.js:1056-1085`、`game.js:3137-3142` | 这是"简陋"的原型；本轮把它升级并推广到每座城市 |
| **平台系统是通用的**：`world.platforms[] = {x,z,r,top,bounce}`；`_supportAt` 取 `max(地形, 平台)` | `world.js:729-734`、`game.js:3203-3213` | **城市天空岛不需要改物理**：把岛面注册成平台就能站、走出边缘自然下落 |
| `onIsle` 只服务农场岛那一座（`_supportAt` 里硬编码 `? 14 : 0`） | `game.js:3204`、`410-412` | 新城**不用 `onIsle`**，因此不动这段老逻辑 → 风险低 |
| 平台的 `bob` **会改 `pf.top`** → 浮云踏板是**真的会动的落脚面** | `game.js:3630-3634` | 岛间间距要按"最坏相位"设计；振幅沿用 0.12~0.14 |
| 弹跳已实现（`pf.bounce` → `vy = 12.5` + 音效 + 尘土） | `game.js:3048-3054` | **弹簧花/蘑菇跳板直接复用**，只需注册 `bounce: true` |
| `_switchCity` 在进城时**懒建**：`world.buildIsland(cur)` + `Object.assign(wIsl, built)` | `game.js:2381-2401`、`world.js:2256` | **天空群岛挂这里生成**：没去过的城零成本 |
| 城市模式只显示当前城的岛组（`want = isl.uid === cur.uid`） | `game.js:3873-3881` | 每城空中的岛不会同时绘制 → draw call 可控 |
| `colliders/platforms` 是**全局数组、从不清理**；按 `{x,z,r}` 判定 | `world.js:725-736` | 各城的岛平台互不干扰（城市间相距很远，距离判定自然失败）；但**三角预算要按单城量** |
| 蛋系统：`EggManager.spawnEgg(word, golden, key, num, pos)`；每关约 6 颗；`_perchEggId()` 已实现"每关 1 颗放高台" | `game.js:515-563` | 本轮升级为"每关 2~3 颗放**岛上**"，沿用同一套挑选/去重思路 |
| 长城（上轮做完）：马道可走、敌楼 7.8 高 | `js/wall-spec.js` | "从长城架桥"的那条通道有了起点 |

**由此确定的两个核心做法**：
- 城市天空岛 = **平台注册**（不碰 `onIsle`、不碰地形），所以物理风险集中在"平台参数"上，容易验收
- 生成时机 = **`buildIsland` 时挂进该城的 `grp`**，跟随现成的"只显示当前城"LOD

## 一、环 A：天空群岛骨架（可独立验收）

### 1.1 新增 `js/sky-isles.js`

纯程序化（**不新增资产**），导出：

```js
buildSkyIsles({ cityKey, cx, cz, r, seed, addPlatform, colC, PROPS, M, scene-grp })
  → { isles:[{x,z,top,r,meshes}], bridges:[...], pads:[...], marks:[...] }
```

**岛造型（按"逼真四要素"，参考图最像真浮岛的地方）**
1. **块状岩底**：倒置锥体 + 沿侧面做 2~3 处**水平岩层色带**（深浅交替），并给顶点 ±0.35 的**确定性抖动**（用 `seed` 派生，避免每帧变）
2. **草顶边缘外挑**：顶层圆盘比岩体**外扩 0.15~0.2**，并加一圈稍暗的"土壤线"（读起来像草皮盖在土上）
3. **岩底与草顶之间的过渡**：一圈更深的土色带
4. **顶部细节**（由装饰点表驱动）：小屋/树/围栏/花丛/灯笼——从 `PROPS` 里挑，不新增几何生成器

**布局（每城 3~4 座）**
- 位置：城市轮廓**外一定距离**的上空（避开城墙正上方，避免与敌楼重叠），高度 **22~30**
- 主岛最大（半径 5~6），其余 3.5~4.5
- **间距 6~9**：单跳 1.85 / 二段跳 3.30 的**水平**射程足够（垂直差同时控制在 ≤1.3）
- 每城用 `seed`（由城市 key 派生）→ 布局稳定且各城不同（可复现，便于校验）

**连接件**
- **木桥**：并行木板 + 两侧绳栏柱（`colR` 矩形碰撞，可走）；长度 ≤8（超过就改成一跳）
- **浮云踏板**：`addPlatform` + `pf.bob = { amp: 0.12, speed: 1.0, phase }`（复用农场云梯同款）
- **弹簧花/蘑菇**：`colTop(x,z,r,top,0,true)` → `bounce:true`（复用现有弹跳）

**平台注册**：每座岛 `addPlatform(x, z, r - 0.3, top)`（岛面整片可站；半径留 0.3 余量避免"站在空气上"）

### 1.2 挂载点

`world.js` 的 `buildOne(isl, ...)` 里，城市分支（`isCity`）末尾调用 `buildSkyIsles(...)`，把结果挂进 `grp`；
`world.skyIsles[key] = {...}` 供 game 层查（蛋位/气流/宝箱都按它定位）。

### 1.3 验收 `scripts/verify-sky-isles.mjs`

1. 每座城都有 **3~4 座**岛，高度在 22~30、半径 ≥3.5
2. **跳得到**：相邻岛水平距离 ≤3.3（二段跳）**或**其间存在桥/浮云/弹簧（三者其一）
3. **岛面可站**：对每座岛，从岛面中心正上方投射线 → `_supportAt` 返回的高度 == 该岛 `top`（±0.05）
4. **走出边缘会下落**：把玩家放到岛面边缘外 0.5 → 若干帧后 `y` 明显下降
5. **桥可走**：沿桥中点采样的 `_supportAt` == 桥面高度
6. **浮云会动**：连续两帧 `pf.top` 不同（bob 生效）
7. **不挡地面**：地面高度处（y≈0）的 `_supportAt` 不受岛影响（岛在 22+ 高处，`pf.top <= y+0.3` 自然排除）
8. 0 页面异常

## 二、环 B：四条上岛/下岛通道（可独立验收）

| 通道 | 上去 | 下来 | 实现要点 |
|---|---|---|---|
| **① 云梯跳** | 复用（城市版新增一段通向第一座岛的矮云） | 跳下来 | 已有机制；只需保证顶段与岛面高差 ≤1.3 |
| **② 上升气流** | 走进**气流光圈**（花/风阵，地面）→ 锁定操作 1.5 秒上升 | 站到气流上方再进入 → **飘落**（缓降状态） | 新增 `_lift` 状态机：上升 `y += 9*dt`；飘落时把 `vy` 限制到 −2.2（缓降）+ 蒲公英/花瓣粒子 |
| **③ 词宠驮飞** | 附近有**已孵化**词宠时按召唤键 → 骑上飞向最近岛 | 岛上再按一次 → 飞回岛心 | 复用现有骑乘/`this.mount` 分支；需要有已孵化词宠（自然成长引导） |
| **④ 长城架桥** | 从**长城马道**（y≈3.1）拉一条木桥到第一座岛 | 走回来 | 起点用 `world.skyIsles[key]` 里的"锚点"（马道上一处） |

**关键约束（写进校验）**：**每条通道都必须可逆** —— 若玩家在岛上且没有下岛手段，就会卡住。
所以验收里对每条通道都断言"双向可用"。

### 验收 `scripts/verify-sky-ways.mjs`
1. 气流光圈存在且在地上（可走到）
2. 走进光圈 → 玩家 `y` 持续上升，1.5 秒后到达岛面高度（±0.5）
3. 从岛上向下走进气流 → 下落速度被限制在缓降区间（`|vy| ≤ 2.6`）且最终安全落地
4. 骑乘通道：调出已孵化词宠 → 触发驮飞 → 玩家落到岛面
5. 长城桥：桥面高度与马道/岛面都接得上（两端 `_supportAt` 差 ≤0.3）
6. 云梯顶段与岛面高差 ≤1.3
7. **可逆性**：对上述每条，反向操作也能回到地面（或岛心）
8. 0 页面异常

## 三、环 C：岛上的蛋 / 宝箱 / 单词机关（用户最在意的"闭环"）

### 3.1 2~3 颗蛋放到岛上
- 沿用 `_perchEggId()` 的挑选思路，新增 `_skyEggIds()`：从本关词里挑 **2~3 颗**（排除剧情钥匙蛋 `GATES` 与 `zone==='sky'` 的金蛋），按 `seed` 分配到**不同的岛**
- 位置：岛面靠中心（避免边缘掉下去）、y = 岛面高度 + 蛋的基准
- **闭环**：跳上岛 → 走过去 → 现有孵蛋流程（念单词 → 孵化）→ 岛上放礼花 → 跳下来找剩下的蛋

### 3.2 宝箱
- 岛上 1 个**木宝箱**（`PROPS` 风格，不加资产）
- 开箱方式：**念对一个单词**（复用现有 challenge 弹窗）
- 奖励：**稀有词宠**（`_applyRare` 已有）或**配饰**（`save` 已有）
- 每箱一次性（存档记 `skychest_<city>`）

### 3.3 单词挑战开机关
- **风车**：念对后转动并播放一次风效（把环 B 的气流"点亮"，给玩家一条明确的上升路径）
- **旗帜**：念对后升起城市色旗（可视成就）
- 每城各一处，均一次性

### 验收 `scripts/verify-sky-reward.mjs`
1. 本关有 **2~3 颗**蛋位于岛上（`y` 落在岛面 ±0.5）
2. 这些蛋**能孵**：模拟走上去 + 完成 challenge → `save.isHatched(id)` 为真
3. 宝箱存在、念对后开箱、奖励入库、**再点不开**（一次性）
4. 风车/旗帜：念对后状态变化；**再念不开**（一次性）
5. 岛上没有蛋被放在边缘（距岛心 ≤ r − 0.6）
6. 0 页面异常

## 四、环 D：采集与动物（可独立验收）

- **可采集**：果子（树上）/ 花（地上）→ 走近按拾取键 → 计数进存档（`save` 新字段 `forage`），可喂词宠（复用喂食入口）
- **动物**：小鸟（绕岛飞的小圆轨）、蝴蝶（绕花丛）、**蒲公英**（可吹散的粒子）
- 都用现成的 `PROPS`/粒子写法，**不新增资产**

### 验收 `scripts/verify-sky-life.mjs`
1. 每城岛上有 ≥3 个可采点；采集后计数 +1、该点消失
2. 采集计数**写进存档**并在重载后保留
3. 可喂给词宠（喂食入口接受果子，好感度 +1）
4. 小鸟/蝴蝶在动（连续两帧位置不同）；蒲公英可被吹散
5. 0 页面异常

## 五、环 E：环境逼真（远景与氛围）

- **远景群山剪影**：城市天空之上的 2 层深色山影（雾色偏移、`fog:false` 或随雾淡化），给"高处的纵深"
- **雾气**：`scene.fog` 在岛上略加浓（用现有的 `_updateDayNight` 钩子按玩家高度插值）→ 高处更像"云上"
- **岛沿草皮外挑 + 阴影**：岛面自身 `receiveShadow`，草顶边缘做出可见厚度（已经在环 A 做）
- **灯笼 / 木栅栏**：岛上一圈低矮栅栏 + 2 盏灯笼（暖色自发光，夜里也看得见）
- **远处淡出**：复用云梯那套"镜头远时降透明度"（`game.js:3635-3638`），避免多岛在远处连成一片

### 验收
- `check-render.mjs` **全部达标**（新增高处几何会影响过曝/上缘/草地采样 —— 这是硬门槛，不放宽）
- `verify-sky.mjs` 仍 12/12（穹顶/云层/暗角不受影响）
- 出图：`.cache/look/skyisles/{overview,bridge,lift,chest}.png`

## 六、分段交付顺序（每段一个提交，各自可玩、可验收）

| 段 | 内容 | 提交后能玩到什么 |
|---|---|---|

## 七、风险与回退

| 风险 | 回退 |
|---|---|
| **浮云踏板会改 `pf.top`**（玩法相关）：间距按最坏相位设计，若实测跳不上就把振幅压到 0.08 并把间距再缩 0.5 | 调 `amp`/间距，不改机制 |
| 高处新增几何顶破 `check-render` 的过曝/上缘/草地采样 | 岛面颜色调暗一档、或把岛高从 22~30 降到 18~24；**不放宽门槛** |
| 三角数与 draw call（每城 3~4 岛 + 桥 + 踏板 ≈ 60~90 mesh） | 只显示当前城（已有 LOD）；超预算就减到 3 座岛、装饰点减半 |
| **玩家卡在岛上**（无下岛手段） | 每条通道都断言"双向可用"；另外**保底**：岛上任意位置跳下去都能落回城市地面（无坠落伤害） |
| 蛋放在岛边缘导致孵化后掉下去 | 蛋位距岛心 ≤ r−0.6（写进校验） |
| 气流/骑乘状态与现有 `climbing/riding/mount` 冲突 | 复用现有状态机字段，不新增并行状态；冲突时以现有字段为准 |
| 重烘风险 | **本轮不重烘**（纯程序化新增，不动 `assets/models`） |
