## 二、⑧ 最大的发现：**孩子要的玩法在城市里根本没成立**

`_perchEggId()` 第一行是 `if (!this.world.perch) return null;` —— `world.perch` 是**农场岛**的石台，
城市模式没有它，于是**城市里永远不分配"高台蛋"**。而 `_putEggOnPerch` 其实**已经支持城市**
（用 `cityLayout` 找最近台面 + 贴台顶），所以只差这一行判断。修掉之后城市观景石台上真的有蛋了，
"跳台阶上去拿蛋"这才成立。在这之上做了三件事：

1. **引导回退**：`_objective()` 指向"最近**可达**的蛋"，而高台蛋不可达（被 `_reachableZone` 排除）
   → 只剩它时 `target` 为 `null` → 箭头与发光小径**一起消失**（孩子不知道该去哪）。
   新增 `_perchGuideTarget()`：指向**最低一级台阶**（`world.jumpSteps[key][0]`）。
2. **台顶奖杯**：观景石台上一只金杯（杯身 + 柄 + 座 + 两侧耳）。
3. **登顶奖励**：踩上台顶（水平 1.8 内且高度接近台顶）→ +3 ⭐ + 彩带 + 主角大笑 + 飘字 🏆 +
   徽章 `perch_<城市>`，**每城只给一次**，奖杯随即隐藏。

## 三、⑨ 用数字代替眼睛

内嵌浏览器面板在本机不可用，所以先写 `scripts/audit-panels.mjs`（三档视口 × 8 面板）量四类
客观代理指标：字号档位与层级跨度、WCAG 对比度、触屏点击区、内容溢出。量出来的问题：

| 问题 | 证据 |
|---|---|
| 所有面板长得一模一样 | `.overlay > div { border-radius: 30px !important; border: 4px solid #FFDCE8 !important }` 把 `#pet-card-card` 写的 22px 抹平成 30px；8 个面板共用同一条彩虹顶带 |
| 点击区点不中 | `#pwd-fold` 16px、`#profile-city` 25px、`.mini-btn` 20px、`.cat-page-btn` 30px、`#btn-switch-spell` 12px、`.round-btn.small` 30px |
| 对比度不足 | 白字压浅粉 CTA **2.6:1**、`--c-text-2` 3.2:1、`#btn-switch-spell` **2.23:1**、"我的城市"未选态 **1.79:1** |
| 标题不统一 | catalog 16px / map 16px 绿 / levelup 24px / picker 16px 渐变字 |
| 长列表撑破面板 | `#catalog-grid` / `#picker-grid` 无滚动上限 |

修法（附加式 CSS 块，删掉即回退）：三档圆角 + 中性暖描边、每面板**语义顶带**（金=奖励/天蓝=地图/
紫=图鉴/薄荷=召唤/粉=行动）、可点控件 ≥40px、带白字的按钮换 `--grad-cta-deep`（4.42:1）、
说明文字统一 `#7A6E63`（4.5:1）、标题统一 19px/900/渐变字。

**两个探针自身的误判（差点得出错误结论）**：
1. 渐变按钮被当透明 → 白字误报 1.02:1；改为取渐变各色点均值作实际底色。
2. 弹出动画首帧是 `scale(.82)`，同一 tick 量 `rect` 会小 18% → 曾据此误判"`min-height` 没生效"
   （其实生效了：33/0.82=40 ✓）。改为等动画落定 + 用 `offsetHeight`。

## 四、⑩ 指标校准（方案明确要求"暗角会改上缘/草地采样，需同步校准"）

- `composerDiff`（开/关后期是否变色）本意是抓**色彩空间错位**（缺 OutputPass 时整幅变色），
  那是**全局**问题；暗角是**设计上**的全画面亮度变化 → 拿它判会把"画面变好看"判成"不达标"
  （实测 0.005 → 0.023，门槛 0.02）。改为只量**中心区**（暗角 `smoothstep(0.55,1)`，
  归一化半径 <0.5 处完全不受影响）：色彩空间错位仍会被抓到，暗角不误报。**门槛未放宽**。
- 分级 `gain` 从 1.03 收回 1.0（原想"用增益抵掉暗角压掉的平均亮度"，但那等于让中心区整体提亮
  3%，正是上面那个指标的取样区）→ 暗角 0.42→0.32、gain 1.0、sat 1.05。
- **harness 自身的不确定性**：`_fpsWatch` 在 6 秒内平均 <25fps 时把 composer 整个拆掉
  （低端机降级），headless 软渲染必然慢 → 同一套参数两趟跑，一趟"有后期"、一趟"无后期"。
  check-render 现在钉住 `_lowFx`。

天空云：穹顶内侧**两层球面片** + 絮状云贴图平铺，半径 940/900、漂移速度 0.0035/0.0060 → 视差。
1 张共享贴图、2 个 draw call、+3840 三角形。触屏整组隐藏；夜里跟着穹顶压暗。
